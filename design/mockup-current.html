7 · Interaksi (tidak terlihat di mockup statis)

Pull-to-refresh — semua daftar (projects, sessions, tasks, files, team, activity, screens, settings). Spinner warna accent.
Auto-scroll chat — hanya jika user berada ≤ 120 px dari bawah; kalau user sedang membaca ke atas, TIDAK dipaksa turun.
Streaming — bubble footer terisi real-time saat message.delta; berhenti jadi bubble permanen saat message.done.
Stop — muncul di header chat hanya saat turn berjalan; kirim cancel ke host.
Stack push/pop — tap "Open mission control →" / sesi / file / screen menimpa layar penuh; tab bar hilang; tombol ‹ kembali satu level.
Sheet — slide-up dari bawah + scrim gelap; tutup via scrim atau ×.
Approval overlay — muncul di atas SEMUA layar remote (termasuk dalam chat); max 2 kartu + "+N more waiting"; resolved otomatis hilang.
Stale-fix — daftar sesi di-refresh otomatis tiap message.done dan saat reconnect host.
Reconnect otomatis — watchdog 25 dtk ping / 75 dtk mati; reconnect tanpa relogin.
Reset host — setelah ack, stack dikosongkan + alert; host restart dan kembali online.
